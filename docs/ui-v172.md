# V1.7.2 - Map-first Operations

## Scope

The existing game now opens on a full-viewport map with a compact company HUD
and an icon dock. Operating screens open inside the play area; closing a screen
returns to the same map position instead of recreating the map.

- Desktop navigation has ten icons with hover and keyboard-focus tooltips.
- Mobile keeps Map, Fleet, Market, Routes and Schedule visible, with secondary
  screens in More. Pause and simulation speed stay available in the HUD.
- Language, account switching, cloud saves and the admin console remain in
  Settings. The cash HUD still opens the console for authorized admins.
- The map offers 2D/globe controls, a layer menu and a collapsible airport board.
  Airport clicks still open the existing route dialog; aircraft clicks open the
  selected independent aircraft in Fleet.
- The globe overview fits the available play area on initialization/reset.
  Its performance hint is a focusable information icon instead of a banner.
- Both views use OpenFreeMap vector airport detail up to zoom 18, with stronger
  runway/taxiway contrast and a Focus Base control. No satellite service or key
  is used. Failed vector maps fall back to the existing OSM raster layer.
- Aircraft Market and Fleet model groups use the existing uploaded side images.
  Purchase previews, registration, affordability and model mappings are retained.
- First Class has distinct Basic, Premium and Luxury photorealistic concept
  images, plus a larger selected-product view. Other cabin images are unchanged.
- Responsive panels, safe-area spacing, reduced motion, visible keyboard focus
  and image placeholders are retained. Fixed dialogs render above the HUD/dock.
- Package branding, page metadata, manifest and PWA cache are version 1.7.2.

There are no changes to economy coefficients, maintenance, timetable rules,
individual aircraft ownership, canonical `game.money`, or local/cloud save
schemas. Existing saved aircraft keep their configurations. The only new
runtime dependency is the official MapLibre GL Leaflet adapter (0.1.4), locked
in pnpm. No database migration is required.

## Files

- `src/components/AppShell.tsx`: viewport layout, HUD and screen navigation.
- `src/components/GameNavigation.tsx`: icon dock, tooltips and mobile menu.
- `src/components/MapScreen.tsx` and `src/components/map/`: map controls and sizing.
- `src/components/AircraftMarketScreen.tsx` and `FleetScreen.tsx`: aircraft imagery.
- `SeatConfigurationModal.tsx` and `SeatProductImage.tsx`: product imagery.
- `src/app/globals.css` and `src/i18n/`: responsive styles and bilingual labels.
- `public/cabin/first-class-products-v172.webp`: local, fictional First Class atlas.
  Generation mode and full prompt are recorded in `public/cabin/README.md`.
- `tests/verifyMapUi.cjs`: optional browser acceptance, not application code.
- `openFreeMapStyle.ts` and `providers/OpenFreeMapLayer.ts`: shared style and
  the 2D vector adapter. Obsolete NASA/satellite styling modules are removed.
- `tests/verifyOpenFreeMap.cjs`: airport/engine/fallback browser acceptance.

Run the existing checks with the locked package manager:

```bash
pnpm test
pnpm run typecheck
pnpm run lint
pnpm run build
```

The optional browser test needs an externally supplied Playwright installation,
a running application, and the compiled helpers produced by `pnpm test`:

```bash
node tests/verifyMapUi.cjs
node tests/verifyOpenFreeMap.cjs
```

`UI_CHECK_URL` defaults to `http://localhost:3015`; `PLAYWRIGHT_MODULE` can point
to an existing Playwright module. `PLAYWRIGHT_CHANNEL` optionally selects an
installed browser. No Playwright dependency is added to the game.

The test uses isolated browser profiles and disposable offline save fixtures,
not the player's save. It checks 1440x1000, 390x844, 320x740 and 844x390 layouts,
all operating screens, focus, persistent map identity/camera, layer and board
controls, airport route opening, dialog stacking, exact purchase cash, unchanged
legacy aircraft, EN/ZH labels and reload. The 390px check also injects a failed
First Class image request and verifies placeholders and reduced motion.
